## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Design draft only. Many research and design ideas recorded in this repository belong in other repositories. Define a protocol and evaluate existing tooling for routing, consolidating, and reconciling backlog items by domain, so specific repositories become domain experts that abstract recurring software and agent concerns. Cover ownership, stable identity, dependencies, provenance, handoff, duplicate detection, and how tasks move without losing context or creating competing queues. Prefer adapting the current backlog mechanism and existing tools over building another tracker. Start with an inventory of domains and candidate repository homes, and ask the author before moving any existing tasks.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Define domain ownership, routing and handoff rules, identity, provenance, and conflict resolution across repositories.
- [ ] #2 Evaluate the current backlog tooling and candidate integrations, and propose a bounded consolidation pilot with author approval required for task movement.
