## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Design draft only. Explore slow review loops using Matt Pocock skills and/or roborev for long-term refactoring, performance work, deep security scans, and chaos engineering. Define triggers, inputs, budgets, evidence, and human handoff rather than starting an unbounded autonomous reviewer. Decide which work belongs in deterministic tests, expert review, or both. Include resource and egress constraints, and require reports to distinguish findings from verified fixes.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Select candidate slow loops for each work class and identify the appropriate existing tools or skills.
- [ ] #2 Define trigger cadence, budgets, review ownership, and evidence required before acting on findings.
