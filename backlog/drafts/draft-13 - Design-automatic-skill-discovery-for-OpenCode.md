## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Design draft only. The author wants relevant installed skills to be discovered and used automatically from keywords or natural-language intent, without explicitly invoking each function. Research current OpenCode skill discovery, loading, matching, and trust controls. Compare Claude Code behavior as a UX reference, not as a compatibility promise. Define how OpenCode could expose relevant skills while avoiding unwanted code execution, hidden data access, or indiscriminate activation. Identify what belongs in OpenCode configuration versus upstream OpenCode or the separate AI tooling repository.
<!-- SECTION:DESCRIPTION:END -->
