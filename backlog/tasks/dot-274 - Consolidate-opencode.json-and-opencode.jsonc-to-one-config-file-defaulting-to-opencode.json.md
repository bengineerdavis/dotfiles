## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Per decision-1 item 3: competing config files are an antipattern even when the tool resolves precedence. This machine has both ~/.config/opencode/opencode.json (generated by lore setup opencode, all providers routed to 127.0.0.1:3207) and ~/.config/opencode/opencode.jsonc (chezmoi-managed, source: home/dot_config/opencode/opencode.jsonc.tmpl). Work: determine whether OpenCode V2 requires JSONC or whether opencode.json suffices (follow the documented approach or the code); if the documented approach conflicts with what lore setup opencode writes, open PRs from forked codebases and raise it upstream. Default to opencode.json (loreai expects it) unless V2 requires JSONC. Then remove the loser file, keep exactly one chezmoi-managed source of truth, and sweep the topic tasks (apps/loreai, apps/opencode) so migrations never leave a second file behind. Include the remediation for the captured dead route: the single config must not leave every provider pointing at the gateway when it is down (ties to DOT-242).
