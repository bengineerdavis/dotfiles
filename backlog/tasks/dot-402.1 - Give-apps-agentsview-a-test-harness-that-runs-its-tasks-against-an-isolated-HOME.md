## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`apps/agentsview` has no tests. Everything it does — claiming a mise entry,
installing an AppImage, and soon writing desktop files — is currently
verified only by hand on one machine.

Build `tests/agentsview/` on the harness shape that already works here:
`tests/gita/test_work_registration.py` runs a throwaway play with
`-i localhost,`, imports the role's task file directly, and runs against an
isolated `HOME` so assertions see a throwaway filesystem.

Ship:

- A `conftest.py` with a fixture that renders a temporary play importing the
  topic's task file, and a `run()` helper that invokes the real
  `ansible-playbook`.
- An isolated `HOME`, `XDG_CONFIG_HOME`, `XDG_DATA_HOME` and `XDG_CACHE_HOME`
  under `tmp_path` for every run, so no assertion can be satisfied by the
  developer's own machine.
- A module-level skip with a named reason when `ansible-playbook` is absent
  (the repo's existing convention), never a silent pass.
- One tracer test that proves the harness works end to end: run the topic's
  install tasks against the isolated HOME and assert a filesystem fact the
  run produced.

Constraints:

- Do not assert on the topic's internal task ordering; assert on state a
  user could observe.
- The fixture must not touch the real `~/.config/mise/config.toml`. Anything
  that would write it must be stubbed or skipped, with the reason named.
- Follow `docs/TESTING.md`: a test that has not been seen to fail is not
  finished.
<!-- SECTION:DESCRIPTION:END -->
