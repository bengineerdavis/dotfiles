## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
OpenCode 2.2.2 strips its provider prefix before calling the gateway; with the V1 Lore plugin disabled, DeepSeek requests fall through to NVIDIA and return 404 even when OpenRouter is the configured upstream. Isolated OpenCode and Lore routing probes show that X-Lore-Provider: openrouter restores the intended route.

Ship:

- An OpenRouter-only provider header in the Lore chezmoi fragment and its rendered configuration, with a regression test and troubleshooting note.

Constraints:

- Preserve the captured V1-compatible provider shape and every unrelated route; do not re-enable the V1 plugin or convert all provider configuration to V2.
- Do not claim restored plugin tools, full per-project attribution, or model-availability filtering.
- Land the deployed-tree change through PR review; do not apply it to the live home.

Agreed with the maintainer 2026-11-04: use the tested configuration-header workaround while the upstream plugin and gateway fixes remain separate.
