* **restart-stale: ctime not mtime; exact comm match; never SIGKILL**: dotfiles/roles/restart-stale answers 'is the running process older than its binary?' with one inequality: process start < binary ctime. Rejected: mtime/birthtime — Homebrew bottles carry archive-internal dates, so they miss real installs; ctime is kernel-set on write-into-place, cannot travel in an archive, and is safe-when-wrong (false positive = cheap restart; false negative = old code silently).
