* **restart-stale: ctime not mtime; exact comm match; never SIGKILL**: dotfiles/roles/restart-stale answers 'is the running process older than its binary?' with one inequality: process start < binary ctime. Rejected: mtime/birthtime — Homebrew bottles carry archive-internal dates, so they miss real installs; ctime is kernel-set on write-into-place, cannot travel in an archive, and is safe-when-wrong (false positive = cheap restart; false negative = old code silently). Match is exact full-path comm (prefix/bundle match would answer for post-update-spawned helpers); unparseable ps rows raise (unknown ≠ not-running). Never SIGKILL — GUI quit is a negotiation (osascript quit with timeout → poll ps → reopen derived bundle only after confirmed exit). Bare systemctl --user needs XDG\_RUNTIME\_DIR — use the systemd module. Topics append one state-based check at end of install; no per-topic notify coupling.
